# Code of Conduct

This project follows the current OWASP Code of Conduct and all applicable OWASP Foundation policies. Be respectful, evidence-led, and mindful of the safety and dignity of people described in intelligence material.

Do not post personal data, case files, identifying details of vulnerable people, allegations about private individuals, exploit material, or operationally sensitive information in issues, pull requests, discussions, chat, or meeting recordings.

Report conduct concerns through the current OWASP reporting path. Project leaders will acknowledge reports promptly, restrict access to harmful material, and escalate through OWASP where appropriate.
