# Changelog

Notable changes to OOSIS programme assets and OOVS releases are recorded here, following the [release policy](programme/RELEASE_POLICY.md).

## OOVS 0.1.0 — 2026-08-05

### Added

- OOVS L1 Foundational baseline with ten testable requirements.
- Machine-readable requirement catalogue and JSON Schema.
- Ten acceptance tests, one per requirement.
- Assessment-result schema, worked synthetic assessment, and expected-failure fixtures.
- Conservative mappings to established public guidance, with non-equivalence statements.
- Governance, maintainer roles, release notes, and release manifest with SHA-256 hashes.
- Validation for JSON Schema conformance, cross-file semantics, Markdown/JSON parity, fixtures, local links, and manifest hashes.
- Preview OIG and OTTM schemas with synthetic examples, and an OOTG scenario template.

### Established

- **OOSIS** as the programme umbrella and **OOVS** as the normative verification standard.
- One consequence-sensitive assurance baseline rather than audience or job-title tiers.
- Source-origin independence checks, provenance-signal limits, structured verification records, pre-work assessment, and correction controls.
- A release line focused on OOVS plus one synthetic cyber-exposure/CTI vertical slice.
