# OOTG — OSINT Testing Guide

## Purpose

OOTG is the practitioner testing guide for OOSIS. It turns techniques and requirements into repeatable scenarios with objectives, expected outputs, validation checks, limitations, and synthetic fixtures.

## Available now

- [Scenario template](templates/OOTG-SCENARIO-TEMPLATE.md)

The first six scenarios support the synthetic cyber-exposure slice on the [roadmap](../docs/roadmap.md).

## Scenario IDs

Each scenario uses `OOTG-v<version>-<domain>-<number>`, such as `OOTG-v0.1.0-MEDIA-003`. Tools, reports, training, and research should cite the versioned identifier.

## Scenario families

- Web and archive intelligence
- Infrastructure and cyber exposure
- Documents, language, and metadata
- Media, time, and geospatial analysis
- Social/persona and network analysis
- Financial/commercial intelligence
- Entity resolution and intelligence fusion
- Information integrity and cognitive security
- Reporting and action products

No operational scenario is accepted without a defined mission need, testable expected result, source/evidence checks, limitations, and a safe fixture or example.
